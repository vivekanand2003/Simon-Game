# 🎮 Simon Game

A simple browser-based memory game built using **HTML, CSS, and JavaScript**.
The game challenges players to remember and repeat an increasing sequence of colors.

---

# 🚀 How to Run the Project

1. Download or clone this repository
2. Open the project folder
3. Double-click **index.html**
4. Game will open in your browser

No installation or server required.

---

# 🕹️ How to Play

1. Press any key to start the game
2. A color button will flash
3. Click the same color
4. Next level → sequence becomes longer
5. Repeat the full sequence correctly

Example:

* Level 1 → Pink
* Level 2 → Pink → Green
* Level 3 → Pink → Green → Purple

If you click the wrong color → **Game Over**

---

# ✨ Features

* Random color sequence generation
* Increasing difficulty each level
* Visual flash animation
* Game over effect
* Keyboard start control

---
